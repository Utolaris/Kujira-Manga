# Kujira-Manga

[JM](https://18comic.vip) 第三方 Android 客户端。

- 系统要求：Android 11（API 30）及以上
- 当前版本：`1.5.0`（versionCode `150`）
- 安装包名：release `kujira.manga`，debug `kujira.manga.debug`
