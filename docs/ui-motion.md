# 交互动效

封面转场、按压反馈、触边震动和收藏图标反馈均在现有 Compose / Glass 界面中实现；
详情进场按 Apple Music 展开播放页的方式分层编排。

## 封面进入详情

首页、搜索、收藏、历史、相关推荐共用 `Comic` 卡片；本地缓存的网格与行卡片也提供来源封面矩形。
`LocalCoverNavigator` 将矩形交给 `CoverNavigationHost`，点击时等待来源页完成进场并刷新绘制，再取得当前导航画面的内存快照，再调用原有的
详情预置与导航操作。预置漫画和合集历史归位逻辑保持在现有 ViewModel / 组合根内。

`CoverDetailTransition` 包裹远端漫画详情与本地缓存详情，统一承接：

| 阶段 | 行为 |
|---|---|
| 封面与背景 | 封面从来源矩形一次移动/缩放到详情页实际封面矩形；背景、顶部按钮和底部玻璃从上往下铺满，共用 448ms 进度 |
| 内容入场 | 封面和背景完成后，右侧介绍向左轻移并淡入，标签/评论向上轻移并淡入，224ms |
| 跟手 | 在内容无法继续竖向滚动时接管未消费距离；整页移动、缩小，背景逐渐变淡 |
| 回弹 | 松手未达到阈值，从当前位置恢复，440ms |
| 退出 | 内容层先反向退场，最多 150ms；封面返回上一页当前可见的位置，背景由底向上收回，256ms |
| 系统侧滑返回 | 手势期间详情保持不动；取消不改变页面；确认后与左上角返回按钮共用完整退场流程 |

绘制分为封面、右侧介绍、背景/顶部按钮/底部玻璃、标签/评论四组。`detailEntryCover` 在真实布局中
记录封面的 GraphicsLayer 与 window 坐标，外层 Canvas 将它绘制到插值矩形；背景单独按屏高裁剪，
不对整页做放大。介绍和标签/评论保持原排版尺寸，等封面落位后才显示，最大位移 12dp。
手机、平板和缓存详情各自报告目标矩形，不写死目标位置；冷加载骨架也报告相同的封面槽位。
平板仅在**横向且宽到能同时放封面 + 420dp 阅读列**时使用双栏（`useDetailColumns`）；
竖屏/窄分屏改用紧凑封面与信息头，整页限宽 840dp 居中，不在两侧留空白。紧凑平板封面最多 240dp，手机仍为 180dp，
骨架和正式封面共用计算。横屏双栏共用 `tabletDetailCoverWidth`：宽度最多 392dp，同时受可用列宽和扣除顶部按钮、
底部操作栏后的高度约束，比例保持 3:4；右侧内容占据剩余宽度。避免固定权重把最大宽度重新撑大，
或在横屏/分屏中把封面推到操作栏后面。平板骨架的介绍和标签也分别使用横向/竖向内容层。
横屏评论仅在右侧滚动，左侧封面保持原位；竖屏头部随完整阅读列滚动。平板底部保留两组操作区，
横竖屏均位于左右下角；手机仍使用单条底栏。封面展开、侧滑确认后完整退出、按压、心形和触边反馈复用同一实现。
平板直接拖动仅允许从实际封面内开始，空白区不能启动整页拖动；滚动容器触边后的拖动处理保留。
`ComicDetailAdaptiveLayout` 始终保留同一份封面、介绍和标签/评论组合。封面宽度/位置、介绍缩进、
内容列宽度/位置和头部预留高度在 320ms 内分别插值；背景持续绘制，整个页面不再降到透明。
介绍内部高度随文字重排过渡；底部两组原生玻璃按钮和右上按钮锚定当前窗口边缘，
不沿旧横屏绝对坐标飞入竖屏。封面/内容列在每个动画帧都按新窗口边界限宽，防止过渡中裁掉正文或控件。
布局动画使用 [Compose 值动画](https://developer.android.com/develop/ui/compose/animation/value-based)，
连续旋转从当前值接续新目标。首次显示直接使用目标值，系统关闭动画或封面正在进退场时不叠加布局动画。
横竖屏共享一个外层滚动状态与一个评论网格状态，骨架使用相同布局；不重建 Glass host 或重播封面展开。
自定义布局显式满足滚动视口的最小高度，不由测量补偿把介绍单独居中。
普通详情与下载详情均从顶部控件避让位置开始排列，不根据正文或评论总高度垂直居中。
评论骨架、空列表、少量评论和加载失败之间切换时，封面与介绍顶部保持不变；短内容自然在页面下方留空。
下载详情在顶部控件必要避让之后再留 8dp，避免封面贴住控件。
本地下载详情在平板横竖屏始终复用同一套布局与封面实例：横屏沿用左封面/右内容；
竖屏采用最多 240dp 的封面与右侧标题作者，标签与缓存状态在下方占完整阅读列，不进入手机满宽封面分支。
平板下载详情去掉通栏标题栏，仅保留普通详情同款的左上角玻璃返回按钮，不显示评论按钮；
本地封面与远程回退封面均采用普通详情的 medium 圆角，封面转场绘制层也保留圆角。
旋转时沿同一 320ms 时钟过渡封面大小、内容位置和宽度，保留滚动状态与持续绘制的模糊背景。
底部阅读与章节/导出两组在横竖屏均锚定左右下角，操作格宽度平滑变化，并在窄窗口中约束总宽度。
平板横屏按漫画详情页的双栏排布（左 3:4 封面、右内容列），封面与内容都带模糊封面背景，右侧内容列不再
被挤成窄条、也不再在右侧留出整列空白；竖屏/分屏单栏用居中 840dp 阅读列。
平板底部两组操作锚定左右下角：左下「阅读」，右下「章节 / 导出」；两组各自只有自己的玻璃底，
外层不再铺一条横贯屏幕的高斯模糊操作条。手机仍是单条悬浮玻璃底栏（最多 600dp 居中）。
MainActivity 按 [Android 配置变更文档](https://developer.android.com/guide/topics/resources/runtime-changes)
处理 orientation / screenSize / smallestScreenSize / screenLayout，不因旋转重建整个 Activity；其他配置仍走系统重建。
窗口尺寸变化时取消旧详情控制器的任务；已提交返回恰好完成一次，旧尺寸的返回覆盖层及时释放，
避免旧坐标和取消中的协程覆盖新布局或重复弹出导航。
来源使用未被滚动容器裁剪的完整封面矩形；屏幕外部分只裁剪绘制，不把残余可见区域拉伸成整张封面。
Glass 的独立 ComposeView 显式转发进场与关闭端口，避免内部控件沿用另一套时钟或普通返回。

飞行时从上一页快照中遮去来源封面，避免出现两张封面。开始保留已显示的缩略图，最后四分之一进度
仅在目标封面 painter 已就绪时混合到详情绘制层，图片仍走原有 loader/cache。
目标未就绪时，原缩略图保留在真实封面图层内，进场结束后也随列表滚动、裁剪和玻璃模糊；
实际图就绪后直接交接，内存命中不等待下一次 LaunchedEffect 才上屏。网络与本地缓存详情共用此保护。
布局等待最多 160ms，错误页或无封面数据不会卡住；编码提取、链接等没有来源快照/矩形的入口
直接显示详情加载骨架与控件，不播放封面展开或延迟内容显示。进场期间拦截内容点击，完成后恢复原交互。

进场、未提交竖向拖动的回弹使用三次贝塞尔 `(0.2, 0, 0, 1)`。
返回退场采用 `LinearEasing`，内容、封面与背景各阶段匀速。系统侧滑进度由 `HierarchicalBackHandler`
消费，不用于驱动详情层，也不触发手势中的截图；确认后才调用与按钮相同的 `DetailMotion.dismiss`。
正常展开的详情无论侧滑幅度和速度如何，都先退内容约 150ms，再完整播放封面/背景的 256ms 退场。
封面与背景同一时钟、无过冲；进入与退出在前一版基础上再提速 25%（时长为原来的 80%）；取消拖动的回弹仍为 440ms。默认退出距离为当前屏高 18%，或沿拖动方向速度超过 1200dp/s。
拖动到屏高 40% 时缩到 0.7；反向越过起点只给 0.2 倍位移，不反向触发退出。
弹窗/评论的阻挡条件在页面组合阶段求值，由 `BlockDetailDrag` 同步到控制器；
避免只在 SideEffect 内读取状态，Glass 子组合更新时外层未重组而漏锁。开启阻挡还会取消已接管的拖动。
横向手势留给内部翻页；尚未提交的拖动遇到第二根手指时取消；评论输入、详情弹窗及缓存导出弹窗阻止整页拖走。

进入详情时不再叠加 NavHost 的水平动画。打开阅读/章节等页面仍使用原导航；返回原详情时不重播展开。
普通漫画详情的顶部按钮和正文始终按状态栏显示时的高度预留空间，避免从全屏阅读器返回时，
状态栏恢复显示导致顶部按钮、封面与正文整体下移。
进程重建后不保存画面快照，也不重播已完成的进场；窗口尺寸改变后旧来源矩形失效；退出仍核对上一页的当前布局，找不到封面才居中淡出。
系统关闭动画时，固定时长动画直接完成。

退出沿进场路径反向匀速推进，封面独立飞行，不再把整页缩成缩略图。
`coverSourceBounds` 注册当前真实封面的页面标识、漫画 ID、完整矩形和可见矩形；条目移除或组合释放即注销。
内容层退场后，记录背景/玻璃和封面的内存位图，再弹出导航。`CoverReturnOverlay` 位于 NavHost 上方，
持有这些临时绘制层，等待上一页恢复布局（最多 160ms），然后在同一页面中查找当前仍可见的同一本漫画。
因此取消收藏、删除、筛选或列表重排后，返回使用实际位置；完全离屏和不存在的封面不会被当作目的地。

有目的地时，原封面绘制暂时隐藏，动画落位后恢复，避免两张封面。没有目的地时，封面从当前矩形
移向屏幕中心，缩到 0.55 并淡出；动画中途目的地被刷新移除，也从当时位置继续改走居中路径。
`CoverReturnPath` 在目的地变化时从上一帧已显示的位置和进度接续，当前帧仍继续移动，不延长结束时间；
忽略不超过 1 个物理像素的落点抖动，避免末段反复重置路径而停帧。
拖动关闭从当前缩放/位移后的位置接续，不先回正。
详情封面因阅读评论而完全离屏时，在返回开始时重新查询 LayoutCoordinates 的实际可见范围；
不复制/飞回离屏封面，不隐藏上一页封面，仅收回背景，使上一页封面在原位自然显露。进场尚未结束时返回也沿当前进度退场，
取消系统侧滑不触发动画或截图。退出覆盖层拦截普通触摸以及新的系统返回手势，不发起网络请求。

背景快照仅用于展示被遮挡的前一页，不接收点击、不替代真实列表状态，也不落盘或写入 SavedState。
以导航条目管理生命周期，条目销毁释放；缓存最多三份背景引用。这里用 Compose 内存快照而不是
继承 Activity 来实现转场，背景在详情停留期间保持进入时的画面；退出时展示恢复后的真实上一页。
退出位图只保留至本次动画结束或组合根释放，不落盘、不进入 SavedState，也不保存详情的 Composable/GraphicsLayer 引用。

确认返回并完成内容退场后，仅准备一次绘制快照；已移除跟手预览、手势期间预取和取消恢复状态。
背景遮罩与输入阻挡状态在绘制/派生状态中读取，避免动画每帧重组整个详情层。封面快照采用浮点平移和缩放，
消除整数坐标取整造成的逐像素跳动。上一页恢复布局的第一帧即隐藏待落位封面，完成后恢复，避免交接时闪出副本。
导航页面的截图记录位于独立 GraphicsLayer，返回覆盖层作为其同级绘制，避免覆盖层进度变化使整个导航画面逐帧重新记录。
返回一旦提交，详情控制器不再响应新拖动和重复关闭。弹出后的覆盖层除消费触摸外，
还用 `HierarchicalBackHandler` 消费新的系统侧滑进度、提交与取消；否则仅遮住触摸仍会让上一页的
NavHost 启动预测返回，移动目标封面并反复重算落点，表现为退场被短暂减速。隔离持续到动画完成，
随后恢复上一页正常输入。
进场未完成时关闭沿当前位置退场，可见的封面位移至少保留 160ms；已经落位且背景已收完时直接结束，不追加空动画。
这些措施针对静态代码可确认的交接工作量与突跳条件；真实设备上的帧耗时仍须用相同手势的运行时数据评估。

## V3 按压

收藏夹顶部文件夹标题点击即展开锚定菜单。漫画详情评论卡片和展开后的回复行点击即复制显示的正文纯文本，
成功后使用底部浮动提示“已复制评论内容”；回复和展开/收起按钮保留各自操作。

- 按下缩到 0.96，用时 120ms；松开或取消恢复 1，用时 200ms。
- `PressFeedbackIndication` 给原有 Foundation `clickable` / `combinedClickable` 增加绘制缩放，保留原涟漪。
- Material 按钮自行创建 ripple，因此公共 `MotionButton` / `MotionTextButton` / `MotionIconButton`、
  tonal/outlined 变体及可点击 `MotionCard` 使用同一 `InteractionSource` 驱动缩放。
  既有页面通过导入别名使用这些适配，原点击、禁用、长按和布局参数保持不变。
- 只缩放绘制，不改变控件排版尺寸或热区。阅读图片的缩放/翻页继续由阅读器手势处理。
- 系统关闭动画时不做装饰性缩放；控件复用或手势取消后恢复正常大小。

## 网格滚动与封面负载

封面按实际加载来源处理：内存缓存立即显示；可见的磁盘缓存允许在滚动中解码并直接显示，
与网络新图共用单路后台解码预算，不等待停下。新解码结果按显示帧逐张释放，避免多列集中上屏。
静态封面按显示尺寸经 Android 原生解码，允许复用更大的清晰缓存，避免源图小于槽位时在 CPU 上放大；
GIF/动态 WebP 保留动画。磁盘无记录的新封面从获取阶段就等待滚动结束，
获取与写缓存最多同时两路；网络新图的解码与上屏同样延后。内存缓存查找不经过获取限流。
磁盘命中在滚动中跳过淡入，静止时继续使用原有 300ms 淡入。
启动维护在每项任务开始前等待可见封面加载结束且停止滚动连续 750ms，避免首页数据刚返回就争抢磁盘和网络。

首页（含骨架）与收藏、搜索等共用分页网格停用额外的逐卡片亚像素绘制补偿。
拖动、惯性起止及触边统一由 Compose 原生滚动处理，减少每帧锚点读取、状态更新与额外图层。
滚动状态以稳定读取函数传到封面组件；开始/停止只更新封面加载门控，不再让整张卡片随之重组。
列数、封面解码与缓存策略保持现有行为；刷新率由系统显示调度选择，LTPO 相关性需设备实测确认。
封面点击和返回转场继续从实时 LayoutCoordinates 读取坐标。

## 触边震动

`ProvideScrollEdgeFeedback` 在主题层包装系统 `OverscrollFactory`，由真实回弹效果观察
拖动/惯性碰撞的剩余距离；通过 `GlassCaptureHost` 显式传递到独立 ComposeView 内的滚动列表。
首页、收藏夹、历史记录、下载中心等使用系统回弹的区域共用此机制，不再依赖导航根部的 nested scroll。
保持系统回弹的节点、距离消费和绘制，仅在用户触发顶部/底部回弹时通过系统 `CLOCK_TICK` 轻震。
同一次连续拉伸只触发一次；回弹结束后再次外拉可重新触发。位置恢复、程序回顶、自动滚动和
纯横向滚动不触发。系统触觉反馈开关由 `View.performHapticFeedback` 处理，不走 `core/AppHaptics`，
因此不受应用内震动设置影响。

首页左上角分类标题点按打开二级菜单，保留菜单震动；通知页以当前分类标题点按打开筛选菜单。
首页右上角「更多」菜单默认宽度 128dp，按图标与两个汉字收紧；大字体时随文字增加宽度，
手机和平板共用，分类菜单等其他菜单的宽度保持各自设置。
该反馈不替换阅读器既有页码快调、删除或收藏成功的业务触感。

## 收藏心形

手机和平板详情底栏、阅读器侧栏的收藏图标使用空心/实心心形，原收藏/取消收藏动作保持不变。
两处共用 `FavoritePulse`，不各自维护一套参数。
点击时图标从当前动作重置为 1，120ms 放大到 1.25，再以一次过冲回弹在 220ms 内恢复。
图标动画回应点击；收藏状态仍由原收藏流程与本地观察更新，失败不伪造成功状态。
连续点击取消前一次图标动画，不叠加循环；系统关闭动画时只更新实际状态。

设置一级页根据当前窗口重算横向留白：平板横屏宽度至少 700dp 时保留两侧 96dp，
竖屏/窄分屏恢复两侧 16dp；用户启用平板悬浮导航时，仅左侧保留 96dp 避让。
横竖屏切换的留白在 240ms 内过渡，滚动列保持同一组合与滚动状态；关闭系统动画时直接使用目标值。

共享玻璃弹窗的面板限制在系统栏及顶部玻璃按钮之外，全屏遮罩仍阻挡背景操作。
章节/缓存/导出弹窗先测量标题与底部按钮，再把剩余高度交给可滚动列表；更新内容面板同样给底部动作让位。
调色弹窗先将 window 像素转换为 dp 再按比例限高。阅读器工具栏、登录卡片等先应用宽度上限，再填满受限宽度。
下载中心的自适应网格直接使用共享 GridCells 与平板 160dp/手机 118dp 最小格宽，按实际内容宽度重新计算列数。
食堂原图查看器使用 `ImageViewportTransform`：按 Fit 后的实际图像尺寸限制位移，窗口改变时立即重新约束，缩回原尺寸时归零。
观看量为 0 时，详情页及详情信息文本中的观看量/喜欢量均显示 `-`，不修改服务器原值；同步为正数后正常显示。

## 剪贴板提示

自动检测到有效漫画后，用户点击取消、系统返回或外部区域关闭，均将请求编码和实际返回的漫画编码记入
`ClipboardDetectionSession`。同一进程中再次识别到这些编码，不重复请求或弹窗，即使文案或前导零改变也不例外。
该状态由 App 组合根使用 Koin 进程单例接入，不写入设置，切后台、锁屏或 Activity 重建不清空，冷启动新进程后恢复检测。
其他编码不受影响；失败请求、尚未展示的检测及点击跳转不会写入取消集合。
